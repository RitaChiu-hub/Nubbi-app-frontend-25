# Nuubi Canvas App Store - Quick Reference

## Installation Quick Links

### LTI 1.3 (Recommended)
1. Admin → Developer Keys → + LTI Key
2. Paste JSON from: [canvas-lti-1.3-config.json](canvas-lti-1.3-config.json)
3. Enable the key & copy Client ID
4. Email Client ID to: support@nuubi.app

### LTI 1.1 (Legacy)
1. Request credentials from: support@nuubi.app
2. Settings → Apps → + App → Paste XML
3. Use XML from: [canvas-lti-1.1-config.xml](canvas-lti-1.1-config.xml)
