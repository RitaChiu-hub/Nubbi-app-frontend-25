## Description

### Short Description (100 characters)
Social learning platform for students to build study communities and track academic progress.

### Full Description

Nuubi is a social learning platform designed to help students succeed through collaboration and community. Students can create study groups, track their progress, communicate in real-time, and earn achievements for their academic accomplishments.

**Key Features:**

🎓 **Study Groups**
- Create and join course-specific study groups
- Automatic enrollment when launching from Canvas
- Organized by course for easy collaboration

📊 **Progress Tracking**
- Visual analytics dashboard
- Track study time and engagement
- Monitor group participation

🏆 **Achievements & Gamification**
- Earn badges for milestones
- Leaderboards for friendly competition
- Certificates for major accomplishments

💬 **Real-time Communication**
- Group chat with threaded discussions
- Share notes and resources
- Post questions and answers

📝 **Collaborative Learning**
- Create and share study posts
- Discussion threads with upvoting
- Rich text and markdown support

🎯 **Task Management**
- Create and assign study tasks
- Track completion and progress
- Integrate with course assignments

**Benefits for Students:**
- Build supportive learning communities
- Stay motivated through gamification
- Access study groups from anywhere
- Track and improve study habits

**Benefits for Instructors:**
- Foster student engagement
- Monitor group participation
- Encourage peer-to-peer learning
- Analytics on student collaboration

**Benefits for Institutions:**
- Improve student retention
- Enhance learning outcomes
- Build campus community
- FERPA compliant data handling

## Technical Details

### LTI Version
- **Primary:** LTI 1.3 (Recommended)
- **Legacy Support:** LTI 1.1

### Integration Type
- External Tool
- Course Navigation
- Link Selection (LTI 1.3)

### Configuration Method
- **LTI 1.3:** Paste JSON (Developer Key)
- **LTI 1.1:** Paste XML

### Configuration Files
- `canvas-lti-1.3-config.json`
- `canvas-lti-1.1-config.xml`

### Placements
- Course Navigation (primary)
- Link Selection / Deep Linking
- Editor Button (LTI 1.1)

### Launch URL
```
https://www.nuubi.app/lti-login
```

### Privacy Level
**Public** - Application receives:
- User name
- User email
- Course information

### Data Usage
All data is used to:
- Create and authenticate user accounts
- Organize course-specific study groups
- Track learning progress and engagement
- Provide personalized recommendations

### Security & Compliance
- HTTPS/TLS encryption

## Installation Requirements

### For Administrators
- Canvas Admin access (for LTI 1.3)
- Course Admin access (for LTI 1.1)
- Contact Nuubi support for backend configuration

### For LTI 1.3
1. Install as Developer Key
2. Copy Client ID
3. Email Client ID to support@nuubi.app
4. Add app to courses

### For LTI 1.1
1. Request credentials from support@nuubi.app
2. Install as External App using XML
3. Configure in course settings
